⚠️ IMPORTANT — on the VPS, bare `docker compose up -d --build` does NOT load
docker-compose.prod.yml (TLS/cert config, port 443). Plain `docker compose`
only auto-merges docker-compose.yml + docker-compose.override.yml. Every
"docker compose up -d --build" run directly on the VPS below should instead
be:
    make prod-up
(defined in the Makefile as: docker compose --profile observability
 -f docker-compose.yml -f docker-compose.prod.yml up -d --build)
Otherwise a routine redeploy can silently drop back to HTTP-only on port 80
with no TLS certs mounted.
